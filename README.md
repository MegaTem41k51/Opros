# БЛИЦ — Streamer Quiz

Версия с простой авторизацией без Twitch.

## Как работает авторизация

1. Пользователь нажимает «Авторизация».
2. Сервер сразу создаёт новую учётную запись.
3. Пользователю выдаётся случайный ID от 0 до 100000.
4. ID хранится на сервере, повторно занять уже используемый ID нельзя.
5. Сессия сохраняется в защищённой HttpOnly cookie.

## Админка

В проекте нет публичной кнопки админки. Владелец открывает секретный маршрут:

`/manage/<ADMIN_PANEL_KEY>`

Задай в Render переменную окружения:

`ADMIN_PANEL_KEY` = длинная случайная строка.

Также рекомендуется задать `SESSION_SECRET` длинной случайной строкой.

После открытия секретной ссылки сервер выдаёт мастер-cookie владельца и открывает `/admin.html`. Админские API дополнительно требуют учётную запись с `admin: true`.

В админке можно:
- смотреть всех пользователей и их ID;
- видеть количество прохождений и правильных ответов;
- редактировать стримеров, вопросы и ответы;
- выдавать права администратора по ID;
- забирать права администратора по ID.

Обычным пользователям ссылка на админку не показывается.

## Render

Build Command: `npm install`
Start Command: `npm start`

Переменные:
- `ADMIN_PANEL_KEY`
- `SESSION_SECRET`
- `NODE_ENV=production`
