# БЛИЦ

Все файлы проекта находятся прямо в одной папке.

## Авторизация
- Нажать «Авторизация».
- Ввести свой ID.
- Нажать «Войти».
- Окно сразу закрывается.
- ID — целое число от 0 до 100000.
- Занятый ID нельзя зарегистрировать повторно.

## Запуск
```bash
npm install
npm start
```

Для авторизации и общей статистики нужен Node-сервер (например Render).
Build Command: `npm install`
Start Command: `npm start`
