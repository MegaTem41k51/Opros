# БЛИЦ — финальный тестовый вариант

Все файлы находятся **прямо в одной папке**. Нет `public/`, `src/` и других вложенных папок.

## Авторизация

Пользователь НЕ получает ID автоматически.

Он нажимает «Авторизация» и сам вводит число от **0 до 100000**.

Примеры:
- 1
- 2
- 16784
- 99999

Если ID уже зарегистрирован, сервер отвечает:
**«Уже есть такой ID. Выбери другой.»**

ID **67 жёстко зарезервирован под администратора** и никогда не выдаётся обычному пользователю.

## Админ

Твой ID: **67**.

Сначала на главной странице создай аккаунт, введя `67`.
После этого `/admin.html` откроет админку.

Другой человек не сможет зарегистрировать `67`, потому что сервер отдельно блокирует этот ID.

В админке можно:
- менять вопросы;
- менять варианты ответов;
- выбирать правильный ответ;
- добавлять и удалять вопросы;
- менять название стримера;
- менять картинку;
- смотреть статистику пользователей.

## Запуск

В папке проекта:

```bash
npm install
npm start
```

Потом:
`http://localhost:3000`

## GitHub / Render

GitHub используется для хранения проекта.
Для работы авторизации, уникальных ID, статистики и админки нужен Node-сервер.

Render:
- Build Command: `npm install`
- Start Command: `npm start`

`data.json` хранит зарегистрированные ID и статистику.
На Render для постоянного хранения после перезапусков нужен Persistent Disk.
