# БЛИЦ — тестовый сайт

Готовый проект в одной папке. Можно целиком загрузить в GitHub.

## Запуск локально
1. Установить Node.js.
2. В этой папке выполнить `npm install`.
3. Выполнить `npm start`.
4. Открыть `http://localhost:3000`.

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable:
  - `ADMIN_ID` = значение из файла `ADMIN_ID.txt`

`ADMIN_ID.txt` добавлен в `.gitignore`, поэтому секрет не должен попасть в GitHub.

## Что есть
- Анонимная авторизация без имени, почты и других персональных данных.
- У каждого посетителя свой случайный ID в cookie.
- Статистика прохождений.
- Админка по секретному ADMIN_ID.
- Редактирование названий и фото стримеров.
- Добавление/удаление вопросов.
- Редактирование 4 вариантов ответов.
- Выбор правильного ответа.
- Таблица статистики пользователей.
- Всё хранится в `data.json`.

Для Render постоянное хранение `data.json` после перезапусков требует Persistent Disk.
