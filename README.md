# БЛИЦ — тестовый вариант

Это первый дизайн сайта, но уже с авторизацией и статистикой.

## Авторизация
- В правом верхнем углу кнопка «Авторизация».
- Авторизация не запрашивает имя, почту, пароль или другие личные данные.
- На сервере создаётся случайный ID от 0 до 100000.
- Один ID не может быть выдан двум аккаунтам.
- ID 67 зарезервирован и не выдаётся обычным пользователям.
- ID 67 — единственный администратор.

## Запуск
`npm install`
`npm start`
Открыть `http://localhost:3000`

## Админка
После авторизации аккаунтом ID 67 открыть `/admin.html`.
Там можно менять вопросы, ответы, правильные ответы, название и картинку стримера, а также смотреть статистику.

## GitHub / Render
GitHub хранит код проекта. Для работы авторизации и статистики нужен Node-сервер (например Render).
Build Command: `npm install`
Start Command: `npm start`

Для постоянного хранения data.json на Render нужен Persistent Disk.
