# БЛИЦ

Все файлы находятся прямо в одной папке.

Авторизация:
- Нажать «Авторизация».
- Ввести ID.
- Нажать «Войти».
- Окно авторизации сразу закрывается.
- После входа можно проходить опрос.
- Если ID уже занят, показывается «Уже есть такой ID».
- ID от 0 до 100000.
- ID 67 — администратор.

Запуск:
npm install
npm start

Админка:
войти на главной странице с ID 67, затем открыть /admin.html.

Для работы авторизации и статистики нужен Node-сервер (например Render).
Build Command: npm install
Start Command: npm start
