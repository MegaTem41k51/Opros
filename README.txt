БЛИЦ — готовый статический сайт

Запуск:
1. Распакуй ZIP.
2. Открой index.html в браузере.

Для публикации:
- Render: Static Site, Build Command не нужен, Publish Directory: .
- Vercel: импортируй папку/репозиторий как обычный static project.

Файлы:
- index.html — разметка
- style.css — дизайн
- app.js — стримеры, вопросы и логика блица

Фотографии:
В карточках используются публичные Twitch-аватарки через unavatar.io/twitch/<ник>. Если сервис недоступен, автоматически показывается запасной аватар с инициалами.

Важно:
В проекте уже есть 7 указанных стримеров. Для первых вопросов используются безопасные базовые вопросы о формате сайта/стриминге; список вопросов можно заменить на конкретные факты о каждом стримере в массиве questions в app.js.
